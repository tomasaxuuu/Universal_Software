# MVT-пайплайн: алгоритм создания и оптимизации элементов

### 1. ПОДГОТОВКА КОНТЕКСТА
- Выделить из ленда блоки, релевантные тестируемому элементу (заголовок, подзаголовок, CTA, изображение)
- Зафиксировать: оффер, ЦА, ключевой недуг/желание, тон коммуникации

### 2. АУДИТ ИСТОРИИ ТЕСТОВ
- Собрать все протестированные варианты: вариант | CTR/CR | win/lose/active
- Выделить паттерны победителей (какие слова, эмоции, длина, формат зашли)
- Выделить антипаттерны проигравших
- Отдельно по текстам, отдельно по фото

### 3. ФОРМИРОВАНИЕ ЕДИНОГО БРИФА
- Составить стандартизированный промпт-шаблон (одинаковый для всех моделей)
- Включить: контекст блока ленда + паттерны побед + антипаттерны + текущий активный вариант
- Задать вектор генерации: эмоция / товар / недуг
- Для фото: описание стиля, что зашло визуально, что нет

### 4. ГЕНЕРАЦИЯ ТЕКСТОВ (параллельно 4 модели)
- Скормить единый бриф каждой модели: Gemini Thinking, Grok Thinking, GPT Thinking, Claude Opus
- Запросить 5–8 вариантов от каждой

### 5. ГЕНЕРАЦИЯ ФОТО (параллельно)
- Скормить ленд + что зашло по фото + что не зашло
- Генерировать через: Grok (Aurora), Gemini (Imagen), GPT (DALL-E / native), Kling + дополнительные (Flux, Ideogram, Recraft)

### 6. КРОСС-ВАЛИДАЦИЯ
- Собрать все варианты (текст + фото) в единый пул
- Скормить независимой модели-судье для ранжирования с обоснованием
- Критерии: понятность, эмоциональность, соответствие ЦА, уникальность, конверсионность
- Отобрать ТОП-3 текстов и ТОП-3 фото для теста
